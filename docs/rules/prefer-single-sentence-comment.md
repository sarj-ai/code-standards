# prefer-single-sentence-comment

Two sentences are the review threshold: the rule stays a warning so teams can shorten prose or make names and types carry the second idea without blocking adoption.

The corpus extractor records comments and docstrings by repository, language, sentence count, and exemption reason. URLs, code spans, decimals, common abbreviations, generated files, directives, licenses, stories, and runtime documentation tags are excluded from sentence splitting or enforcement.
