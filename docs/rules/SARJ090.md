# SARJ090 — Prefer one-sentence comments

Exactly two sentence-equivalents are advisory: shorten the prose to one local
fact or make the code carry it. The warning is deliberately non-blocking; three
or more sentences belong to SARJ091.

Sentence counting ignores physical wrapping, URLs, decimals, common
abbreviations, and code spans. Generated/vendor files, licenses, directives,
and runtime-consumed tool/route/CLI documentation are excluded.
