# SARJ302 — AI execution artifacts

SARJ302 reports execution briefs, handoffs, status reports, and Markdown change
diaries with repeated fix-pass, verification-pass, QA-pass, or session-status
headings. Keep current design, operation, evidence, and decision facts in a
durable document, then delete the chronology.

Durable locations include README, CHANGELOG, CONTRIBUTING, SECURITY,
AGENTS/CLAUDE instructions, `.github/`, `docs/`, `architecture/`, and ADR trees.
A durable path is not a waiver for a change diary: repeated execution-log
headings inside a README still fail.
