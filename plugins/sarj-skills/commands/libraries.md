# Libraries and platform capabilities

Use the [audit protocol](../skills/audit-protocol/SKILL.md).

Compare custom infrastructure and duplicate, heavy or abandoned dependencies
with maintained native/library capabilities. Inspect detected manifests,
lockfiles and callers without installing during discovery. Justify substitution
by contract fidelity, maintenance/security, license, runtime/bundle cost,
transitive dependencies, migration effort and net code removed. Novelty or
popularity alone does not justify churn; deterministic API-preference findings
are already owned by their rules.
