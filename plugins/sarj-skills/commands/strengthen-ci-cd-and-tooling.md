# CI/CD and tooling

Use the [audit protocol](../skills/audit-protocol/SKILL.md).

Trace required gates through protected delivery paths and review deployment
ordering, rollback/health behavior and configuration drift. Native security,
reproducibility and runtime rules own their deterministic cases.

For workflow optimization, reproduce a bounded bottleneck; compare pinned
baseline/candidate revisions with equivalent inputs, harness, caches and
concurrency. Separate queue wait from execution and measure task-ready time,
first useful error, repeated work or output cost. Keep final qualification gates;
scoped green checks and more test cases do not establish value. Modernization
needs a demonstrated support, safety, cost or simplification benefit.
