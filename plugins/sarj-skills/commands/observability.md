# Observability

Use the [audit protocol](../skills/audit-protocol/SKILL.md).

Trace request/job identity across async/distributed boundaries. Review missing
failure, retry, drop, saturation and latency signals, unusable structure/context
and levels that hide incidents or cause alert fatigue. Respect the configured
library, record errors once and instrument actionable boundaries. Native rules
own deterministic secret/payload logging violations; review remaining privacy
exposure without reproducing sensitive values.
