---
name: test-value
description: Write or review pytest and Vitest tests for distinct regression coverage and safe redundancy removal.
---

Name the contract, plausible wrong outcome, recurring consumer and cheapest faithful
oracle. Charge probes, fixtures, wrappers and cleanup the same review cost as
production code. Reuse sufficient coverage; line counts, coverage percentages and
helper self-tests alone justify no addition. Retain required gates.

Before adding cases, assess whether existing types, tagged variants, exhaustive
handling, schema-derived contracts or declarative constraints prevent the wrong
outcome more cheaply. Verify actual checker scope/overrides and consumed ingress
validation; account for defaults, coercion, bypasses, instance revalidation and
mutation. Static brands do not validate external input; freezing may be shallow.
Count abstractions, dependencies, configuration and analyzer upkeep too. Use
representative bad edits and valid near misses only when needed to establish a
proposed replacement. Preserve schema intent, custom validation, serialization
and effect/compatibility tests where the retained control does not establish
those contracts.

Use `code-standards observe --test-value --base BASE` when inspection leaves a
coverage or redundancy question; omit `--base` for a suite-wide question.
Executable Oxlint config needs `--trust-repository-code`. Treat the observer as
advisory evidence, not an extra completion gate.

Delete/merge only when retained cases reject the same wrong outcomes with
compatible inputs, actions, fixtures, marks, runtime, order and effects.
Preserve ordered scenarios and smoke/compatibility/representation contracts.
Read [oracles](references/oracles.md) for integration and fixture-liveness decisions.

Verify affected fixtures/consumers with the applicable native checks. Reuse
passing evidence when its source, tools and inputs are unchanged; review passes
do not require fresh runs. Summarize material keep/strengthen/merge/delete
decisions with the wrong outcome and covering evidence. Advisory/incomplete
results never prove redundancy.
